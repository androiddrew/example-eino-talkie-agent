---
name: web-search
description: Search the web for facts and current information, such as news, sports, weather, prices, people, places, dates and anything you aren't sure of.
---
Call the web-search tool with a short search query in args, such as
["tallest mountain in Africa"] or ["weather Boston today"].

Search before answering any question about facts in the world, especially
anything recent or that changes over time, instead of answering from memory.
Don't search for chit-chat, opinions, arithmetic, or questions about this
conversation.

The tool returns numbered results, each with a title, a snippet and its
source. Answer from them in one to three short sentences. You can name a
source, such as "according to Wikipedia", but never say a web address. If the
results don't answer the question, say you couldn't find out. If the tool
fails, say web search isn't working right now.
